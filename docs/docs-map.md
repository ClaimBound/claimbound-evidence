# Documentation map

Where each page lives. The documentation site is assembled by `scripts/build_docs_site.py` (the list `COPIED`
maps each source file to a flat page name) and the navigation is in `mkdocs.yml`. New pages are added to both.

## Archive and examples

`docs/archive/README.md` is the index of the older evidence-card and campaign material. The files themselves
(`docs/nasa/`, `docs/esa/`, `docs/public_claims/`, `docs/registry/`, `docs/evidence_cards/`, and the card
documents in `docs/*.md`) were not moved, so existing links and tests keep working.

## Maintenance rules

- Every command shown in the README is run by `tests/test_readme_examples.py`.
- `docs/CLI.md` is generated; `tests/test_docs_site.py` fails when it is stale.
- A statement about behaviour must match `docs/spec/CORE_SPEC.md` and the code. Anything not implemented is
  marked "planned".
