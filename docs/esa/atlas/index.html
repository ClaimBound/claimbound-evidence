How to read the map

A coverage map,
not a mission ranking.

  1. 01

    One page per row

    Each row freezes one selected official ESA mission landing page.

  2. 02

    One gate per cell

    A cell asks whether exact terms required by one preregistered gate occur inside that page boundary.

  3. 03

    Amber preserves uncertainty

    Limited coverage means the page did not support that gate. The search was not silently widened to another source.

What the experiment established

Scale is useful only when the boundary remains inspectable.

The campaign shows that ClaimBound can generate, validate, register, and present hundreds of narrow records without turning keyword presence into a broad scientific endorsement. The lasting value is the rerunnable baseline: later runs can measure source drift against these exact claims and hashes.
