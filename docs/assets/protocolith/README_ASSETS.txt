CURRENT LOGO (concept E, chosen 2026-11-18): an isometric monolith with an amber P carved in its left face, standing on four
strata slabs, one slab per ledger layer; the slab edges carry hash-like ticks (heights from the first hex digits of
SHA-256("protocolith")), the amber rule along the top edge marks the ledger head. Generated by scripts/build_logo.py
(plain SVG, no fonts for the mark; the wordmark paths come from the earlier lockup). favicon.svg is a simplified version
(two slabs, no ticks). logo-mark-512.png is rendered from logo-mark.svg. Earlier concepts A, B and C are kept below.


CONCEPTS
  A  Monolith: faceted slab, carved dashed lines read as protocol steps, last step amber.
  B  Cut P: stone block with a P cut through it (the stone refills the counter), chamfered corner,
     a row of 12 hash-like ticks. Tick heights come from the first 12 hex digits of SHA-256("protocolith").
  C  Seal: notched rim with 60 teeth, concentric incised rings, notch at the top, carved P.
  Shipped set (logo.svg, logo-dark.svg, logo-mark.svg, favicon.svg, social-preview.*) is concept B.

RECOMMENDATION: B (Cut P)
It is the only mark that stays legible and unmistakable at 16 px (see favicon), because the letter
itself is the shape; a P cut into stone says "protocol cut in stone" directly. The hash ticks give the
technical, verifiable character without any cliche (no lock, shield or chain), and the amber accent
marks "recorded" detail. A is more literal but reads as a generic tower/server at small sizes;
C is handsome but detailed rings and teeth vanish below about 32 px.

DEMO GIF (demo.gif): generated by scripts/build_demo_gif.py from a real run (no hand edited text)
  uv run --no-project --with pillow python scripts/build_demo_gif.py
The script copies examples/quickstart to a temporary directory and runs init, freeze, record, verify-ledger, summary,
issue 1 and atlas. It then changes one word of the ledger (PASSED to FAILED) and runs verify-ledger again, which exits 1.
Only hexadecimal strings of 40 or more characters are shortened to 12 characters plus "...". The frames contain the date of
the run (it is part of the card ids). Pillow is needed only for this script.

WORKFLOW GIF (workflow.gif): drawn with Pillow, 900x300, 10 fps, loops. Captioned "Workflow overview"
and "Design overview, not a product demo".
